## Браузерная проверка в GitHub

[Прогон PR checks](https://github.com/maneki2804/Graal/actions/runs/40376579978) проверял коммит `b0ca45f85f247228f4b44a59cecafd143a2d0793` с тем же кодом приложения, тестами и конфигурацией, что и итоговый PR. Последующие изменения этого отчёта носят только документальный характер.

- Прошли загрузка health/title без JS-ошибок и сценарий двух клиентов от комнаты до карты.
- Сценарий повторного выбора классов/входа в бой упал на `page.locator('#btn-back-classpick').click()`, ещё до запуска боя. Повтор дал тот же результат.
- В стандартном viewport Desktop Chrome **1280×720** кнопка «Назад» обрезается нижней границей. Trace показывает доступную высоту около `0.1px` у кнопки и перехват pointer events элементом `html` после попытки прокрутки. Снимок подтверждает обрезанный экран выбора классов.
- `public/` полностью совпадает с исходным `main`; это обнаруженный дефект существующего интерфейса. В рамках запрета на изменения UI он оставлен без исправления. Размер viewport, обычный click и проверка сохранены; force-click, skip и увеличение таймаута не применялись.
- Диагностика сохранена в [артефакте Playwright](https://github.com/maneki2804/Graal/actions/runs/40376579978/artifacts/12674103625) с retention 7 дней.

PR остаётся черновиком: инструменты готовы к дальнейшей разработке, но перед слиянием нужна отдельная разрешённая правка доступности кнопок на этом экране и повторный успешный прогон. Статус browser намеренно остаётся красным, чтобы проблема не терялась.

Набор тестов начальный: он не покрывает все эффекты боя, поведение ботов, таймеры очистки комнат и восстановление соединений.

В приложении остались исходные предупреждения ESLint и фиксированный Railway WS URL. Последний обходит только тестовая среда; обычный локальный клиент продолжает использовать production URL. README содержит исторические сведения о правилах и адресах; источником истины служит код. Эти вопросы не исправлялись, поскольку задача исключает изменение механики, интерфейса и продакшен-деплоя.

Изменение `server.js` ограничено экспортом движка и условием запуска сетевой части. `public/`, `railway.toml`, команда `start`, runtime `engines` и объявление зависимости `ws` сохранены. В `main` напрямую ничего не записывается. PR не должен объединяться автоматически.

Проект подготовлен для дальнейшей разработки в отдельной ветке на Node.js 24. Браузерные проверки работают в GitHub и выявляют описанный дефект интерфейса; проект пока не имеет полностью зелёного CI. Локальная установка Chromium дополнительно ограничена доступом к CDN.
