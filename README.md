# ⚱ Graal Hunt

Браузерная многопользовательская стратегическая игра. До 4 команд соревнуются на общей гексагональной карте: исследуют территорию, собирают предметы, вступают в сражения и первыми добираются до Грааля.

---

## Что это за игра

**Graal Hunt** — пошаговая многопользовательская игра для 2–4 команд. Каждая команда играет из своего браузера по общей ссылке:

- Карта из шестиугольных клеток (равнины, лес, горы, вода, зона Грааля)
- Каждая команда — 4 игрока с уникальными способностями
- Предметы на карте усиливают команду
- Боевая система с атаками, отступлением и лечением
- Туманом войны скрываются клетки, пока их не посетит хотя бы один игрок команды
- Таймер на каждый ход

## Запуск локально

**Требования**: Node.js 18+, зависимость `ws@^8.18.0`

```bash
git clone https://github.com/maneki2804/Graal.git
cd Graal
npm install
npm start
```

Сервер запустится на `http://localhost:8765`.  
Открой в браузере → **Создать комнату** → поделись кодом с другими командами.

## Где менять правила и визуал

### Игровые правила (только `server.js`)

| Что изменить | Где найти |
|---|---|
| Очки HP игроков | `const PLAYER_HP` |
| Размер карты | `const MAP_SIZE` |
| Длительность хода | параметр `turnDuration` при создании комнаты (или константа по умолчанию) |
| Скорость по типам местности | `MOVE_COST` / `TERRAIN_COST` |
| Правила боя | функции `resolveCombat`, `doCombatRound` |
| Эффекты способностей | блок `switch(ability)` внутри обработчиков |
| Эффекты предметов | массив/объект `ITEM_EFFECTS` |

### Визуал (только `public/`)

| Что изменить | Файл |
|---|---|
| Цвета команд | `TEAM_COLORS` в `game.js`, CSS-переменные `--t0..--t3` в `style.css` |
| Цвета местности на Canvas | `TERRAIN_COLORS` в `game.js` |
| Глобальная цветовая схема | CSS-переменные `:root { ... }` в `style.css` |
| Тексты кнопок и надписей | `index.html` |
| Длительность анимаций | `--fast`, `--mid` в `style.css` |
| Скорость и размер шрифта | блок `/* ── Typography ──` в `style.css` |

## Деплой на Railway

Игра уже задеплоена:  
**`wss://graal-production-4ca6.up.railway.app`**

### Чтобы задеплоить заново или обновить:

1. Сделай push в ветку `main` репозитория `maneki2804/Graal`
2. Railway подхватит изменения автоматически (если включён Auto Deploy)
3. Или: зайди в [railway.app](https://railway.app) → выбери проект → **Deploy**

### Переменные окружения Railway

| Переменная | Значение |
|---|---|
| `PORT` | Задаётся Railway автоматически. Не меняй. |

### Проверка работы

- Health-check: `https://graal-production-4ca6.up.railway.app/health` → должен ответить `ok`
- Если Railway показывает ошибку — смотри вкладку **Logs** в дашборде

## Устранение неполадок

| Проблема | Решение |
|---|---|
| Браузер пишет "Not Found" при открытии Railway URL | Это нормально — сервер отвечает только на WebSocket и `/health`. Открывай клиент локально или через Perplexity Computer. |
| Игроки не видят друг друга в лобби | Убедись, что все вводят **одинаковый код комнаты** (заглавными буквами). |
| WS отключается сразу | Проверь, что `RAILWAY_URL` в `public/game.js` совпадает с реальным Railway URL. |
| Не загружается карта | Открой DevTools → вкладку Console — там будет конкретная ошибка. |
| npm install падает | Убедись, что Node.js ≥ 18: `node -v` |
| Railway не видит репо при деплое | В GitHub → Settings → Applications → Railway → проверь, что репо `Graal` включён в список доступных. |
